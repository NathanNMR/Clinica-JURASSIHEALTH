# Acesso mobile por Web responsiva

Conforme validação do professor orientador, a JURASSIHEALTH atende o uso mobile pelo mesmo site Web responsivo, sem necessidade de aplicativo nativo.

A interface utiliza:
- viewport responsivo;
- media queries;
- navegação adaptativa;
- formulários em coluna única em telas menores;
- botões com área de toque adequada;
- tabelas com rolagem horizontal;
- tipografia fluida;
- layouts que passam de múltiplas colunas para uma coluna.

Sugestão de evidências no relatório:
1. página inicial em desktop;
2. página inicial em smartphone;
3. login em smartphone;
4. área do paciente;
5. agendamento;
6. tabela de consultas.
