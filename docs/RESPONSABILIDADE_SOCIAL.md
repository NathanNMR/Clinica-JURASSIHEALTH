# Responsabilidade social, diversidade e inclusão

- Controle de acesso baseado em função, não em características pessoais.
- Coleta mínima de dados.
- Linguagem respeitosa.
- Interface responsiva para ampliar acesso.
- Labels de formulário e contraste legível.
- Navegação por teclado.
- Compatibilidade planejada com leitores de tela.
- Manutenção de canais alternativos para pessoas com dificuldade de acesso digital.
